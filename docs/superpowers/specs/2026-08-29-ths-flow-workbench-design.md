# 同花顺板块资金流工作台设计

**日期：** 2026-08-29  
**状态：** 已根据参考界面草图确认

## 目标

在现有板块资金分时流向页面上，引入同花顺板块资金流作为低延迟实验源，并把参考图中有价值的分析能力整合进一个单页工作台：曲线图、排序图、赛车图、回放、实时切换、当前图表导出和清晰的数据口径标识。

明确不引入参考图底部的“个股池、板块池、工具箱、我的”导航，也不复制第三方品牌、水印或页面素材。

## 设计范围

### 数据源

新增 `ths` provider，直接调用同花顺资金流页面的公开分页接口：

- 行业：`/funds/hyzjl/field/tradezdf/order/desc/ajax/1/free/1/`
- 概念：`/funds/gnzjl/field/tradezdf/order/desc/ajax/1/free/1/`

接口返回 HTML 表格，金额单位为亿元；采集器归一化为项目内部的元单位。板块代码从板块详情链接提取，提取不到时使用带来源和类型的稳定回退键。请求失败时首个页面抛出明确错误，后续分页允许保留已取得的部分结果并记录警告。

同花顺 provider 默认轮询间隔为 60 秒，但“请求快”不等于“源数据刚刚刷新”；页面始终展示 provider、指标口径和最近采集时间。新浪和东方财富 provider 保留为可切换备选，不混合写入同一条曲线。

### 页面布局

沿用单文件 `web/viewer.html` 和 ECharts，不引入底部导航：

1. 顶部标题、数据源徽标、交易日/更新时间和刷新状态。
2. 顶部视图标签：`曲线图`、`排序图`、`赛车图`。
3. 工具栏：`8s`、`13s`、`15s`、`30s` 回放时长，`导出 CSV`、`导出图片`。
4. 主图区域：
   - 曲线图显示板块累计净流入，末端显示板块名和数值。
   - 排序图按选定时点的净流入排序，红色代表流入、绿色代表流出。
   - 赛车图使用同一组排序数据随时间轴推进，保持轻量动画，不引入第三方视频生成依赖。
5. 图表底部：播放/暂停、回到起点、时间滑块、时间标签和`实时`按钮。
6. 主图下方：最新排名摘要和口径说明卡片。

页面默认以中国时区选择当天文件；`?date=mock` 继续用于离线演示。真实日期页面每 60 秒重新请求当天 JSON，刷新失败时保留最近一次成功图表并显示错误。

### 数据与交互规则

- 真实数据只显示已经采集到的时点，未来未采集点保持空值，不人为延伸到收盘。
- 回放只使用当前已加载数据，不修改数据库；切换“实时”跳到最后一个有效时点并停止回放。
- 排序图和赛车图的排名由当前游标的最后有效值计算；空值不参与排序。
- CSV 导出包含日期、时点、板块代码、板块名称和各板块净流入亿元值。
- 图片导出使用 ECharts 当前视图的 PNG 数据 URL，不上传外部服务。
- 同名板块来自行业和概念时，保留现有按最新绝对值选择的规则；页面用 provider/metric_label 说明口径。

## 代码边界

- `ths.py`：同花顺 HTML 分页请求、编码处理、表格行解析和字段归一化。
- `providers.py`：增加 `ths` provider 分发。
- `config.yaml`：将默认 provider/指标/轮询配置切换为同花顺，保留新浪映射和原有 watchlist。
- `collector.py`：沿用现有采集循环，接受 `ths` provider；不改变 SQLite 表结构。
- `export.py`：避免把未来未采集时点填充为最后一个值。
- `web/viewer.html`：实现三视图、回放、实时切换、导出、响应式布局和刷新状态。
- `tests/test_ths.py`：覆盖 HTML 行解析、金额/涨跌幅单位、分页、去重和异常。
- `tests/test_pipeline.py`：覆盖 provider 分发、未来空值、viewer 静态交互契约。
- `requirements.txt`：只保留现有轻量依赖；不强制把完整 AkShare 作为运行依赖。

## 错误处理与兼容性

- 同花顺页面可能返回 GBK 编码或字段结构变化；请求层显式设置编码，解析字段不足时跳过该行并记录警告。
- 首页失败让本轮采集失败，避免导出空快照；后续页失败返回前面已取得的数据。
- provider 之间的净流入统计口径不同，配置和导出 JSON 不能把不同来源的记录混在一起。
- 继续支持 `--provider sina` 和 `--provider eastmoney`，便于回退和 A/B 对照。

## 验收标准

- `python -m unittest discover -v` 全部通过。
- 同花顺行业和概念真实页面均能在当前网络路径加载，返回板块表格和净额字段。
- 本地运行采集器时，`--provider ths` 能完成一轮归一化、入库和当天 JSON 导出。
- 页面三种视图均可切换；回放、实时、时间轴、CSV、PNG 控件均可用。
- 本地 HTTP 页面在 mock 数据下可渲染非空 ECharts canvas，且在 dpr=1 和 dpr=2 下无空白或裁剪。
- 不创建底部导航，不提交数据库和运行时 JSON，不改变现有 GitHub 远端历史。
